Como começar

  1. No terminal: pip install -r requirements.txt
  2. Copie .env.example para .env e coloque sua ANTHROPIC_API_KEY.
  3. Teste com python modulos/01-prompts/exemplo.py
  4. Abra a sessão IA · Mentor e digite /mentor para receber o primeiro passo.
  5. Siga para o agente que o Mentor indicar.
Modelo padrão dos exemplos: claude-opus-5-5 · SDK oficial anthropic (Python)
