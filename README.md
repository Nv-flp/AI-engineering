# AI Engineering

Meu negócio próprio com IA: ganhar mais, com menos horas.

## Os 3 agentes
- **`/estrategista`**: decide o que fazer (negócio, oferta, preço, plano da semana).
- **`/executor`**: faz o trabalho comigo (páginas, posts, propostas, mensagens).
- **`/automatizador`**: tira o trabalho repetido.

Não sei qual usar? Começo pelo `/estrategista`.

## Arquivos
```
negocio.md      o plano: negócio, oferta, meta, placar, tarefas, diário
perfil.md       quem sou, tempo e dinheiro disponíveis
ideias.md       ideias guardadas para depois
entregas/       o que o executor produz
automacoes/     o que o automatizador cria
```
